Community plugins

Plugins add importers, exporters, and lyric tools. Every listing here is a sandboxed WebAssembly module with a published SHA-256 hash, declared permissions, and a matching manifest.

i
Plugins are WebAssembly only. They cannot read your files, lyrics, or network unless they declare the permission and you approve it at install. Themes and plugins are reviewed separately.

Installing a plugin

  1. Open the plugin store

    In TTML Tool, open Plugin Management and switch to Plugin Store. Listings load from this page's registry.

  2. Read the permissions

    Install shows the exact permissions the plugin declares. Approve only what you understand; network and files:write are worth a second look.

  3. Or sideload both files

    Download the .wasm and its plugin.json, then choose Sideload .wasm + plugin.json in the Installed tab. Sideloaded plugins skip the registry hash check, so only do this with files you trust.
