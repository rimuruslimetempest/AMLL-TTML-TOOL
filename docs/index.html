Make your editor feel like yours.

TTML Tool themes change the colors of the New interface without touching your lyrics, timing, shortcuts, or projects. Browse community palettes, preview them, and install with one file.

Browse themes Download TTML Tool

Windows, macOS, and Linux · Free and open source

Built for the way TTML Tool works

Themes are color schemes plus optional CSS. No scripts, no background services, and nothing that changes timing.

◐

Light and dark

Every theme carries its own palette. Performance mode and reduced motion still fall back to readable flat colors.

⌁

CSS and JSON only

A theme is a theme.json file and optional CSS. Remote URLs and scripts are rejected before install.

↺

Your files stay put

Installing a theme never edits projects, audio, saved splits, or shortcuts. Remove it whenever you like.

How installing works

Two ways in, depending on whether you want to check the file first.

Submit yours
1

Download the theme file

Use the Download button on a theme card. You get a JSON file with the palette and its CSS.

2

Import in Settings

Open Settings → Appearance → Themes → Manage themes → Import and choose the file. A preview appears before anything is installed.

3

Or browse in the app

Turn on Show community themes inside the app to load this registry in the theme manager. Installs still require a click and a matching SHA-256 hash.
