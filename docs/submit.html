Submit your theme

Themes are added by pull request. Nothing appears on this page until Rimurulover reviews and merges your change.

Open a pull request Ask first with an issue

What to send

  1. Build and test your theme

    Export it from Settings → Appearance → Themes, or write a theme.json that follows THEMES.md. Test it in the app, in both New and Classic UI, and with Performance mode on.

  2. Add the theme file and a preview

    Put the JSON in docs/registry/themes/<id>.json and a 16:9 preview in docs/assets/previews/<id>.svg (or .png). Keep the theme file under 2 MB.

  3. Add a registry entry

    Edit docs/registry/themes.json and add your id, name, author, version, description, tags, appearance, preview path, download path, SHA-256, performance level, and minimum app version. The SHA-256 is the hash of the exact JSON file.

  4. Run the checks

    node scripts/validate-theme-registry.mjs must pass. The same check runs automatically on your pull request and fails on a bad field, a hash mismatch, a missing preview, or a theme that contains remote URLs or scripts.

  5. Wait for review

    Open the pull request and describe the theme in your own words. Merging is the only thing that publishes it. Please do not bump the version for cosmetic edits; use a new version when the palette changes.

Registry entry example

{
  "id": "aurora",
  "name": "Aurora",
  "author": "your-github-name",
  "version": "1.0.0",
  "description": "A short description in your own words.",
  "tags": ["dark", "green", "calm"],
  "appearance": "dark",
  "preview": "assets/previews/aurora.svg",
  "download": "registry/themes/aurora.json",
  "sha256": "<64 lowercase hex characters>",
  "size": 12345,
  "performance": "light",
  "minAppVersion": "1.0.0",
  "verified": false
}
!
Themes are CSS and JSON only. Do not include JavaScript, remote fonts, @import from another site, or images loaded from the network. Those entries are rejected by the validator and by the app's importer.
◆
Plugins are not part of this marketplace yet. TTML Tool has a separate WASM plugin registry. Do not submit plugins here; plugin listings are coming later with their own review process.

Review and removal

Rimurulover reviews every entry. A theme can be removed if it breaks the app, contains content that does not belong to the author, or stops matching its published hash. Removing an entry does not reach into anyone's installed copy; people can delete a theme in Settings.
