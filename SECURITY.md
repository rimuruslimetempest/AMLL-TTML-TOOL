# Security Policy

## Supported versions

Security fixes are provided for the latest release on the `main` branch. Older releases may not receive fixes.

## Reporting a vulnerability

**Please do not open a public issue for a security problem.**

Email **rimurusamllttmltool@gmail.com** with:

- A short description of the issue and its impact.
- Steps to reproduce, or a minimal proof of concept.
- The app version and Windows version where you observed it.
- Any suggested fix, if you have one.

Do not include lyrics, audio files, passwords, API keys, access tokens, or other people's private data in the report. If a credential may have been exposed, replace or revoke it immediately; do not send the live value.

I will acknowledge a complete report as soon as practical, investigate it, and coordinate a fix and disclosure timeline with you. Please give me a reasonable opportunity to fix the issue before publishing details.

## Scope

This policy covers the TTML Tool source code and official release binaries in this repository. It does not cover third-party services, Firebase projects you configure yourself, or forks maintained by other people.
